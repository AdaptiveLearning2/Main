# Pinned to the versions verified working on 2026-07-22 (Python 3.12); the same
# pins were re-verified with the full test suite on Python 3.14.7 on 2026-08-20.
#
# Previously unpinned, so every fresh venv resolved to whatever was current --
# which is how the pydantic and sympy mismatches during setup happened. Direct
# dependencies only: transitive versions are still resolved by pip, but each of
# these constrains its own subtree (fastapi pins a starlette range, supabase
# pins its postgrest/realtime siblings, and so on).
#
# Deliberately not a full `pip freeze`: CI installs this file on ubuntu while
# development happens on Windows, and a freeze taken on either one bakes in
# platform-specific resolution (uvicorn[standard] pulls uvloop on Linux but not
# Windows). Every package below is cross-platform.
#
# Runtime only. Test-only packages live in requirements-dev.txt, which pulls
# this file in -- so `pip install -r requirements-dev.txt` gets you both.
#
# To upgrade: bump a pin, rebuild the venv, run `python -m pytest tests/`.
